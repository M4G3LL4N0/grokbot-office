# Release notes — 0.1.0

## Release theme

A public-safe reference control layer for coordinating a large external workforce through a small persistent GrokBot supervisor core and an explicit AgentOS execution boundary.

## Verified capabilities

- Canonical registry validation: 134 conceptual roles, 3 anchors, no duplicate names.
- Deterministic role/profile and A2A smoke behavior.
- Local synthetic examples for the requested task classes.
- Typecheck, 149 tests, build, doctor, and publication validation paths.
- Production dependency audit: no known high-severity findings.
- No credentials or private state required for local validation.

## Optional, unconfigured, and planned

- External cloud worker execution and provider credentials.
- Paid model/provider calls.
- Browser session ownership and cloud supervision.
- Human approval UX and durable production deployment.
- Reviewed external adapters, portable manifests, and optional cloud supervision.

## Known limitations

- The package does not create external bots.
- A role definition is not runtime evidence.
- Generated archives and local operational state are intentionally excluded.
- The inherited parent repository remote is not a project remote.

## Migration

Keep local state outside the public candidate, set an explicit resource policy, and register only reviewed adapters. See [MIGRATION.md](MIGRATION.md).

## Release status

The public target is `https://github.com/M4G3LL4N0/grokbot-office`. The release tag and remote verification are recorded in [PUBLICATION_AUDIT.md](PUBLICATION_AUDIT.md).
