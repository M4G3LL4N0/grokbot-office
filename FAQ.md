# FAQ

### Does this create 134 bots?

No. The registry contains 134 conceptual roles. The local reference selects
three reference supervisors and leaves 131 virtual. A role is not a runtime.

### Does it run paid workers?

No. Local validation and examples do not call paid providers. External
execution requires an explicit adapter, credentials, approval, and resource
policy.

### Is the cloud path live?

No live external execution is claimed by this package. Simulations are
labeled as simulations.

### What is the relationship with AgentOS?

AgentOS is an optional execution control plane. This package owns supervisory
role context; AgentOS routes and executes through reviewed capabilities.

### What makes an artifact reusable?

Fresh provenance, a stable output contract, a verification result, a security
scope, and an invalidation rule.

### How do I report a security issue?

Do not open a public issue with secrets or private evidence. Follow the
security contact process in `CONTRIBUTING.md` and share only sanitized,
minimal reproduction details.
