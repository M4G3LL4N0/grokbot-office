# Known limitations

- The public candidate describes a local reference model, not a live external
  workforce.
- Three reference supervisors and 131 virtual roles are configuration
  semantics, not provisioning instructions.
- External execution requires reviewed adapters, credentials, approvals, and
  infrastructure isolation.
- Some operational source paths and generated archives are intentionally
  excluded until the publication boundary is clean.
- The current public remote is unverified; no GitHub URL is claimed.
- The package has no hosted service, browser session manager, or billing
  controller.
