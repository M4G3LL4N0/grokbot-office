# GrokBot Office

GrokBot Office provides a CLI for inspecting and operating on workforce definitions. The repository marks publication as enabled and includes a publication validator; run its validation, build, test, and CI checks before publishing.

- **Version in repository:** `0.1.0`
- **License:** MIT
- **Source:** [GitHub](https://github.com/M4G3LL4N0/grokbot-office)
- **Project site:** [https://grokbot-office-xi.vercel.app](https://grokbot-office-xi.vercel.app)

## Installation

The command below is the intended npm installation form; it is not evidence that this distribution has been published yet.

```sh
npm install --global grokbot-office
```


For a local checkout before an npm release:

```sh
pnpm install --frozen-lockfile
pnpm build
node dist/src/cli.js --help
```
## First commands

```sh
grokbot-office --help
grok --help
```
